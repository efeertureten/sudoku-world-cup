# Code of Conduct

Sudoku World Cup is built by people from many countries, which is rather the point of the game. We want everyone to feel welcome here.

## What we expect

- Be respectful and assume good intent. Disagree about ideas, not people.
- Welcome newcomers and be patient with questions.
- Give and accept constructive feedback gracefully.
- Treat every country, language and culture with the same respect the leaderboard does.

## What is not acceptable

- Harassment, insults, slurs or personal attacks, in public or in private.
- Discrimination based on nationality, ethnicity, religion, gender, sexual orientation, disability, age or any other identity.
- Sexualised language or imagery.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.

## Scope and enforcement

This applies to all project spaces (issues, pull requests, discussions, chat) and to anyone representing the project. Report problems privately to the maintainers listed in `.github/CODEOWNERS` or through a GitHub security advisory. Reports are handled confidentially. Maintainers may edit or remove contributions and warn, suspend or ban participants who break these rules.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
