# ADR 0008: MIT license

Status: accepted (2026-10-13)

**Context.** The goal is the widest possible use: people should be able to self-host, learn from and adapt the game.

**Decision.** MIT.

**Consequences.** Anyone, including commercial hosts, may use the code without sharing changes. If the community later prefers that hosted forks share their improvements, relicensing future versions under AGPL-3.0 would need contributor agreement.
